# 案例：堆叠卡片轮播

一个完整的端到端例子，把路径、时序、图层、测量四件事串起来。数值是某次实做的实测值，换素材时按同样方法重新取。

## 形态

N 张卡呈扇形堆叠在一个裁剪舞台里，前卡最大、最清晰、位置最高，后面的卡依次变小、下沉、左移、加模糊。每隔一段时间前卡沿弧线向右下方坠落出画，后面的卡同时上移就位，队尾补进一张新卡。N 步一循环，无限播放。

难点有四个，按解决顺序：图层顺序不能打帧、弧线路径要平滑、各角色的时序不同步、循环要严丝合缝。

## 槽位表

舞台 196×120，裁剪。三个可见槽加两个画外虚拟槽。宽度严格等比（高 = 宽 × 1.2489），模糊按景深递增。

| 槽 | 原点 | 旋转 | 宽 | 缩放 | 模糊 | 不透明度 |
|---|---|---|---|---|---|---|
| A 前 | (39, 16) | 0° | 221 | 1.0000 | 0 | 1 |
| B 中 | (20, 36.4978) | 5.14° | 176 | 0.7964 | 1 | 1 |
| C 后 | (5.1201, 67.5218) | 14.71° | 166 | 0.7511 | 2 | 1 |
| D 补位 | (3, 79.3569) | 20.7435° | 145 | 0.6561 | 3 | 1 |
| D′ 起始 | (1.5, 87) | 26.5° | 130 | 0.5882 | 3.5 | 0 |

坠落路径三个航点（占一步的 33% / 67% / 100%）：

| 航点 | 原点 | 旋转 | 宽 | 模糊 | 不透明度 |
|---|---|---|---|---|---|
| F1 | (62.0303, 46) | −6° | 221 | 1.5 | 0.90 |
| F2 | (99.1523, 94) | −21.0541° | 221 | 5 | 0.25 |
| F3 | (98.1523, 138) | −21.0541° | 221 | 6 | 0 |

换位的中间姿态（占该段的 50%）：B→A 取 (33.9347, 22.4514) / 1.14° / 宽 181.6968 / 模糊 0.8；C→B 取 (14.8984, 51.7036) / 10.71° / 宽 171.3732 / 模糊 1.8。

D′ 和坠落的模糊、不透明度是设计决定的，其余全部来自故事板实测。**画外槽要用四角包围盒反解**，别估：F3 的四角最小 y 是 138 > 120，确认完全出画。

## 图层结构

节点数 = 可见槽位数 + 卡片数，推导见 [motion-math.md](motion-math.md) 第 7 节。3 个槽 + 4 张卡 = 7 个节点，自下而上：

| z | 节点 | 静止槽 | 行程 |
|---|---|---|---|
| 0 | X4 | C | 第 4 步补位 |
| 1 | X3 | B | 第 3 步补位 → 第 4 步 C→B |
| 2 | X2 | A | 第 2 步补位 → C→B → B→A |
| 3 | X1 | C | 第 1 步补位 → C→B → B→A → 坠落 |
| 4 | C0 | C | C→B → B→A → 坠落 |
| 5 | B0 | B | B→A → 坠落 |
| 6 | A0 | A | 坠落 |

补位节点的**静止槽跟着克隆源走，不要 rescale**（见 [figma-motion-api.md](figma-motion-api.md) 第 13 条）。尺寸差由 `SCALE_XY` 轨道承担，轨道的缩放是相对节点自身静止尺寸的，起始尺寸多少都不影响结果。

末帧由 X2 / X3 / X4 占据 A / B / C，与首帧的 A0 / B0 / C0 一一对应，循环无缝。

## 时序

每步 2.0s：过渡 0.45s + 停留 1.55s。四步共 8.0s，过渡分别始于 1.55 / 3.55 / 5.55 / 7.55。

**每个角色一个窗口、一条时间映射曲线**，不要统一：

| 角色 | 窗口（相对每步起点） | 时间映射 |
|---|---|---|
| 坠落 A→F3 | 0 → 0.45s | 缓入 `CB(0.30, 0.10, 0.70, 0.85)` |
| 中卡 B→A | 0 → 0.30s | 缓出 `CB(0.33, 1, 0.68, 1)` |
| 后卡 C→B | 0 → 0.30s | 缓出 `CB(0.33, 1, 0.68, 1)` |
| 补位 D′→C | 0.08 → 0.45s | 缓出 `CB(0.33, 1, 0.68, 1)` |

换位在 0.30s 完成、坠落和补位到 0.45s 才结束，这个错位来自故事板本身——它的第 3 帧里换位已就位而坠落还在半空。**别硬套同一个进度**。

坠落单独用缓入的理由见 [motion-craft.md](motion-craft.md)「进出用不同的时间映射」。

## 路径与采样

三层解耦，做法和代码见 [motion-math.md](motion-math.md) 第 6 节：航点 → 时间映射 → 密集采样，段间用线性缓动。位置和旋转用 Catmull-Rom，宽度、模糊、不透明度用线性。

**不透明度也走同一套采样**：在航点上给 `op` 值，补位卡的淡入（D′ 的 0 → D 的 1）和坠落卡的淡出（1 → 0.90 → 0.25 → 0）都由路径生成，不再单独写两点式轨道。

采样密度直接决定丝滑度，见下方测量三。

## 三段测量脚本

### 一、背景暴露栅格

查「过渡中途露馅」。在舞台打点统计未被任何卡覆盖的比例，减去静止基线。

```js
const GX=[],GY=[]; for(let x=2;x<196;x+=4)GX.push(x); for(let y=2;y<120;y+=4)GY.push(y);
const un=t=>{ const qs=cards.map(n=>poly(n,t)).filter(g=>g.op>0.5).map(g=>g.pts); let u=0;
  for(const x of GX) for(const y of GY) if(!qs.some(q=>inQuad([x,y],q))) u++;
  return u/(GX.length*GY.length); };
const base=un(0); let peak={t:0,v:base};
for(let t=0;t<=DUR;t+=0.03){ const v=un(+t.toFixed(2)); if(v>peak.v) peak={t:+t.toFixed(2),v}; }
```

**先定位再修。** 把峰值时刻未覆盖、但静止时被覆盖的格子挑出来求包围盒：

```js
const K=c=>c[0]+','+c[1], rest=new Set(cells(0).map(K));
const gap=cells(peak.t).filter(c=>!rest.has(K(c)));
```

实测教训：凭现象猜缺口在后排，改完暴露反而从 3.95pp 升到 4.22pp；实际缺口在顶部条带（槽 A 顶边 y=16、槽 B 顶边 y=36.5，前卡走后差 20px）。

**基准是故事板隐含值，不是 0。** 本例静止基线 22.04%，峰值 5.6pp，等于故事板中间帧算出来的值（最上层卡在 y=22.45，比静止的 16 低 6.45px，乘画面宽度约 5.4pp）。压得更低就是在改设计。

### 二、落位逐帧位移（台阶检测）

按 1/60s 取相邻两帧，算同一张卡四角的最大位移。**采样太稀会出现连续多帧同速再跳档**：

```
7 个采样点：5.881 5.883 5.884 | 8.599 8.589 8.580 | 6.952 6.951 6.950 | 3.658 3.658 3.658 | 1.395 ... | 0.207 ... | 0
13 个采样点：6.057 5.884 5.791  7.066 8.595 10.115  7.907 6.945 5.996  4.352 3.654 2.964  1.831 ...  0.362 ...  0
```

前者是六级台阶（每三帧一个速度值），观感是一顿一顿；后者逐帧变化。**取样间隔要小于两个渲染帧**（60fps 下 ≤ 33ms）。

用这个指标时要**只取单张卡**。取全场最大值会被坠落卡主导，读不出落位的问题。

残留的速度峰如果来自路径本身（例如宽度变化集中在后半段），加密采样解决不了，要改中间帧的姿态值。

### 三、循环接缝三项

```js
// 1. 首末帧按组件身份配对，量四角偏差、模糊差、不透明度差 —— 应全为 0
// 2. 跨接逐帧：frameMove(DUR, 0) 应为 0
// 3. 与其他步对照：循环边界前 N 帧的逐帧位移，应与其他步收尾相同
```

三项都为 0 说明数据层没有接缝，此时若仍观察到卡顿，来源是播放器或落位收尾的速度台阶（走测量二）。

**别急着上「时长缩短一帧」这类消除重复帧的技巧**：首末帧已经完全一致时，缩短反而引入约 0.1px 残差。先确认播放器行为。

## 迭代教训

| 版本 | 做法 | 结果 |
|---|---|---|
| 接力式 | 每个槽先被补上、原占位的再走，一步 0.90s | 背景暴露 0，但被评价为「非常不流畅、顺序不对」 |
| 同时动 | 所有角色在 0.45s 内一起走 | 「变化正常流畅、前后关系衔接得上」 |
| 加淡出与加密 | 坠落加模糊淡出、采样 7 → 13 点 | 注意力交接干净，落位台阶消除 |

最大的一条：**把「背景暴露为 0」当成目标是错的。** 观感的第一决定因素是运动结构（同时动还是接力），不是覆盖率。指标用来定位问题，不能用来定义目标。
